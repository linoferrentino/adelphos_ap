### Current state of adelphos

This first release of adelphos can do only the simple trading of
objects in upper level agorai.

But this is only the first step; I have decided to let it public
because I would like some feedback, but there are already planned
evolutions of the system, some short term, other long term, other
in the wish list as I do not have the necessary expertise to do
them.

As this is an open source project I gladly accept volunteers to
grab one of these points.


### Short term goals

#### The trust line and the alias semantic

Currently a user in adelphos is at the base of a pyramid; this
allows the building of tree-like structures, much like a file
system.

The next step would be to give the user the possibility to create
an alias of himself, so that there are two aliases in the system,
but effectively they are the same user.

This is much like the symbolic link feature in a file system; a
file is stored only once and the other instances are only links
to the original file

This would allow a more complex (*and realistic*) routing.

For example if Jane wants to sell her used phone she puts the ads
in her family's agora, so the ad is *bubbled* to the upper
levels. But she might be also in her school's family: someone
might be interested in the object there. 

The alias feature would allow her to put the ad only once and the
system would publish it automatically in the school's agora.


#### The Ergon


Currently adelphos allows trading only of goods, but the idea is
to create also the trading of ergon (Works in Greek).

### Long term goals

### Geo localization

Adelphos should handle the localization of the families and
agora, this especially for the ergon feature

### The gui

Adelphos should have a gui: maybe an Android gui so that it could
be run as an app.
