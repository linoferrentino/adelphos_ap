## Introduction

Adelphos (ἀδελφός, the ancient Greek word for "brother") is a system that
enables users to exchange goods and services using a virtual currency based
on trust between the users.

The main difference from other similar systems (LETS, CreditCommons,
Ripple) is that Adelphos is a closed ecosystem: it does not rely on
external carriers: if a user sells an object it *creates* also the shipping
of the item to the buyer using a chain of steps much like packets in a IP
protocol.

Each steps has a responsible (dikastes) and a servant (diakonos) who will
handle the routing one leg of a time and each leg is registered in the
system with its cost.

Adelphos is also able to limit the amount of trust (credit) which we give
to the system and that the system gives to us; in this way the seller is
limited by the system to only sell until a certain amount (so that his
credit is secured) but also the buyer is limited to a certain amount (so
that he cannot exploit the system over a certain point).

These limits are changed gradually by the users' feedback, so the main
objective of adelphos is thus to allow users to form an increasingly strong
web of trust.
