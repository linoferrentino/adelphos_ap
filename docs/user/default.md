## Intended audience

 
This document is intended for end users, i.e. not technical people who will
use adelphos. A Technical Documentation to install and modify adelphos,
intended for technical people, can be found in the source tree [on
github](https://github.com/linoferrentino/adelphos_ap)

## Where to start?

Adelphos is a new system and it might be unfamiliar; in general
when it comes to a new system a picture is worth a thousand words
and practice is better than a lot of theory.

But there is the necessity of both: if you are a person who would
like to play soon with adelphos I encourage to start from 
the [Tutorial](content/Tutorial) which will offer you a quick
bird's eye view.

If you would like to know the theory behind it you can start from
the [Basic Concepts](content/BasicConcepts) instead.

Of course the two views are complementary, feel free to skim both
to get an idea of what adelphos is and if it can interest you.
